# AI小说编辑器 1.4.6：安卓 UI 修复

基线为用户已全部验收的 1.4.5。1.4.5 源码和安装包保留；1.4.6 单独修复本轮反馈，尚未由用户验收。

## 蓝图页面

- 手机上使用一个页面滚动容器，恢复稿提示可折叠说明并随页面滚动，避免固定占据章节编辑空间。
- 剧情树和章节详情的导航背景覆盖滚动区上缘，面板独立隔离绘制，滚动内容不会从导航上方露出。
- 恢复稿新增“删除恢复稿”，确认后删除当前恢复稿及其续写链的可恢复内容并持久退役旧句柄。正式蓝图、正文和其他恢复稿保留，用量记录保留。
- 真正进行中的生成拒绝删除；崩溃遗留状态在确认没有实际请求后按原用量规则收尾。旧编辑标签关闭，旧句柄不能继续或保存以恢复已删除内容。

## 生成完成提示

连续生成正文或设定后，完成提示只显示最新一条，并在原定时间后消失。触摸事件不再触发鼠标悬停暂停，避免 Android 兼容鼠标事件使提示永久停留。切换或重新打开作品会清理旧完成提示。

用户确认的入口是“本次写作选项”。在手机短视口内，旧完成条目会盖进该窗口的内容区；打开写作或架构指导现在会清除这些旧条目，编辑期间后台完成的新条目也不会叠到表单上。关闭指导后，后续完成提示恢复正常。架构页与旧架构文档页共用相同处理。

后台生成历史、未完成任务、错误和常驻恢复提示、作者指导输入及未保存正文均保留。

## 验证与安装

定向回归和正式移动端页面验证的最终结果记录在同目录的 `2026-11-16-android-ui-146-validation.json`。指导相关 Chrome 回归 112/112；恢复稿与蓝图页面另有独立后端及正式移动构建验证。测试使用合成作品、恢复稿及通知，不调用真实模型，也不读取用户小说、用户截图或 API Key。

安卓版本为 1.4.6 / 1004006，继续使用原包名和原签名覆盖安装，不先卸载。Windows 继续使用已验收的 1.4.5 安装包。本轮不产生 Windows 1.4.6 安装包，也不修改已验收同步的触发时机或内容范围。

本地打包的签名/资源校验与真实手机验收分别记录；本轮实体手机表现仍待用户安装后确认。
